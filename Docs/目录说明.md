# Clawdroid 目录说明

## 目录目标

本说明用于解释当前仓库的顶层目录划分，明确哪些目录属于 Clawdroid 主工程，哪些目录属于正式文档，哪些目录只是第三方参考资料，从而避免继续把 Brain Host、Runtime Executor 与外部调研源码混在一起理解。

## 顶层目录

### `ClawApp/`

用于存放 Android 客户端相关内容，代表面向用户安装的 APK 工程（Brain Host）。详见 [ClawApp/README.md](../ClawApp/README.md)。

当前包含：

- `settings.gradle.kts` / `build.gradle.kts` / `gradle.properties` — Gradle 工程
- `local.properties` — SDK 路径与可选本地密钥（勿提交）
- `app/` — 主模块；`com.clawdroid.app` 包结构大致为：
  - `ui/` — Compose 壳（Overview / Chat / Settings）与 ViewModel
  - `ui/rich/` — 富文本聊天（Markdown / 代码 / KaTeX / Mermaid）
  - `data/` — SharedPreferences / JSON 持久化（`*Store`）
  - `agent/` — Agent 内核（Goal/Plan/Run/Policy/Kernel）
  - `ai/` / `chat/` / `orchestrator/` / `skills/` — 模型回合、路由、工具环、Skill/Catalog Agent
  - `model/` — 多供应商 Model API 客户端
  - `tools/` — 工具目录、Dispatcher、handlers、域服务
  - `mcp/` — 手机 MCP Server 与 Assist 客户端
  - `runtime/` / `ipc/` — Runtime 高层客户端与 UDS 帧/鉴权
  - `termux/` — Termux `RUN_COMMAND` 桥与应用内终端 UI
  - `env/` / `shizuku/` — 环境探测、权限、Shizuku
  - `service/` — 无障碍、通知监听、`:sandbox` Shell 服务
  - `focus/` / `xposed/` — 焦点/view 存储与 LSPosed 适配器
  - `fault/` / `automation/` — 故障隔离与自动化状态
- `xposed-stubs/` — 本地编译桩
- `keystore/` — 发布签名说明

### `ClawRuntime/`

Root 执行侧与 Magisk 模块。详见 [ClawRuntime/README.md](../ClawRuntime/README.md)。

- `runtime/` — Go 守护进程
- `magisk/` — 模块打包（`module.prop`、`service.sh`、`config/`、`webroot/`）
- `scripts/` — `build-runtime.ps1`、`build-magisk.ps1`、`sync-shared-secret.ps1`
- `dist/` — `ClawRuntime-magisk.zip`

## 当前推荐理解方式

1. `ClawApp` = 用户层、AI 层和工具编排层
2. `ClawRuntime` = Root 执行与 Magisk 打包
3. `Docs` = 正式文档；`Docs/archive` = 非权威历史
4. `GitSource` = 受边界约束的参考资料

共享密钥推荐由仓库根 `local.properties` 统一保存，经脚本同步到 App `BuildConfig` 与 Magisk `config/runtime.yaml`。

## App 内部分层

详见 [architecture.md](architecture.md)。摘要：

1. **编排**（`ai` / `chat` / `orchestrator` / `skills`）
2. **工具**（`tools` / `mcp`）— Dispatcher + ToolHandler
3. **执行通道**（`runtime` / `ipc` / `service` / `shizuku` / `termux` / `xposed`+`focus`）
4. **持久化**（`data`）
5. **展示**（`ui` / `ui.rich`）

当前执行优先级见 [下一步计划.md](下一步计划.md)。
